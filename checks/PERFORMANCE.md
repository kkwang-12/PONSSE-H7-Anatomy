# 动画优化验证 · 2026-10-15

保留同一份 846 实体 SVG 几何与展开模型，把每帧的工作改为合成 11 个透明总成图层。正常与高亮外观分别缓存；图片只从页面内嵌 SVG 生成，仍支持直接离线打开。

## 相同动作对比

本机无界面 Edge，1100 × 1250 视口，120 个等间隔姿态，组装 → 展开 → 组装。结果用于比较当前实现，不代表所有电脑或浏览器的实际显示帧率。

| 场景 | 平均帧率 | 帧间隔 P95 |
| --- | ---: | ---: |
| 原 SVG 实现 | 10.6 fps | 152.9 ms |
| 优化后深色 | 125.1 fps | 14.1 ms |
| 优化后切换高亮 | 104.5 fps | 20.9 ms |
| 优化后 2× 高分屏 | 142.8 fps | 7.0 ms |
| 优化后浅色 | 141.6 fps | 7.4 ms |

实时文档节点从 12,702 减至 48。深色普通场景 120 帧累计布局耗时从 3.956 秒降至 0.014 秒。原始数值及测量脚本分别见 `performance-comparison.json` 与 `performance-compare.mjs`。

## 交互和显示

- 11 个总成均通过可见像素命中与悬停选中检查；透明区域不会抢占鼠标。
- 正常图层的 44 个边界角像素全部透明，排除矩形背景遮挡。
- 动画静止后连续 50 次鼠标移动，重新绘制次数为 0。
- 人为阻塞主线程 120 ms 后，展开仍在约 2.03 秒内完成。
- 快速展开/收拢反转、组件标签、键盘、触摸、滑动不误触、减少动态效果模式均已检查。
- 窗口尺寸改变时，画布尺寸与命中坐标同步；无横向溢出。
- 模拟图片准备失败后，原 SVG 仍能展开、选择、复位。
- 深色、浅色、高分屏、手机及局部放大截图已人工查看。运行日志未出现控制台异常。

首次打开需要约 2–3 秒准备图层，期间保留原始静态图。缓存仅保留在当前页面内；重新打开会重新准备。图层线宽随模型缩放，高倍率放大有位图分辨率上限。原始 SVG 及几何源码仍保留在 HTML 和项目源码中。
