# PONSSE H7 采伐头结构与作业动画

一个可以直接在浏览器中打开的机械可视化项目。通过结构展开和倒木加工动画，展示 PONSSE H7 采伐头的主要机构，以及刀组、送料辊、测长轮、链锯与木材之间的运动配合。

项目依据实物照片、产品视图及手册组件图制作，以 Anatomy 工具构建结构图形，采用灰阶等距视角呈现，提供深色和浅色两个版本。适合用于工作原理讲解、课堂展示和交互演示。

## 项目展示什么

### 结构展示

查看机头的 11 个主要总成，包括主机架、吊架与回转器、倾转架、上部防护罩、左右送料辊、打枝刀组、中央辊与测长组件、链锯总成。悬停或选择部件，可以展开机头并阅读对应说明。

### 加工演示

**张开入位 → 夹紧 → 第一轮送料打枝 → 减速停车 → 第一段锯切 → 回锯分离 → 第二轮送料 → 第二段锯切与回锯 → 释放余料。**
以一根带枝条的倒木为对象，演示约 31 秒的完整加工流程：
动画重点表现三个关系：

- 送料时，木材前进，辊轮与测长轮转动，枝条经过刀口后被去除。
- 锯切时，木材停止，刀辊继续夹持，锯链和锯板执行切割。
- 两段之间保持夹持，回锯后继续送料，完成加工后才打开刀辊释放余料。

支持暂停、重播、慢放和按步骤查看，便于观察每个机构的动作。

## 快速开始

查看演示无需安装 Node.js，也不需要启动服务器或联网。

1. 下载项目文件；如果收到的是 ZIP 压缩包，请先解压。
2. 使用 Edge 或 Chrome 打开以下任意一个 HTML 文件：

| 文件 | 内容 |
| --- | --- |
| `index-dark.html` | 深色页面，包含结构展示与加工演示 |
| `index.html` | 浅色页面，包含结构展示与加工演示 |

Windows 用户也可以双击启动脚本：

| 脚本 | 功能 |
| --- | --- |
| `Dark.cmd` | 打开深色页面 |
| `Light.cmd` | 打开浅色页面 |
| `打开加工演示.cmd` | 直接打开深色加工演示，初始为暂停状态 |

加工演示需要浏览器支持 **WebGL2**。建议使用已启用图形加速的 Edge 或 Chrome。

## 使用方法

页面顶部的“结构展示 / 加工演示”用于切换模式。

### 查看结构

- **桌面端：**将鼠标移入机头画面，模型展开；离开画面及组件标签后复位。
- **查看部件：**悬停、聚焦或点击下方组件标签，查看对应总成和说明。
- **固定展开：**点击左下角“展开 / 复位”按钮切换状态。
- **触屏设备：**轻点部件查看说明，轻点画面空白处切换展开状态；可正常上下滑动页面。

首次打开时会准备图层，期间先显示静态结构图。准备完成后，本页内的展开和复位会复用缓存。

### 播放加工动画

1. 点击顶部“加工演示”。
2. 点击“播放”开始，播放中可以随时暂停。
3. 使用速度选择框切换 **0.25×、0.5×、1×**。
4. 点击下方九个步骤按钮，跳到该步骤的代表性状态并暂停。
5. 点击“重播”，从头观看完整流程。

播放完成后，动画停在释放余料的状态。悬停或轻点部件仍可查看说明，不会触发结构展开。切回结构展示会暂停加工，并保留加工进度。

浏览器切到后台或画面离开可视区域时暂停计时，返回后恢复原先的播放状态。如果系统开启“减少动态效果”，加工演示改为通过“下一步”静态查看各阶段。

### 键盘操作

先点击画面或使用 Tab 键聚焦画面，再使用以下按键：

| 按键 | 结构展示 | 加工演示 |
| --- | --- | --- |
| 空格 / Enter | 切换展开与复位 | 播放 / 暂停；减少动态效果模式下进入下一步 |
| 方向键 | 切换组件 | 切换加工步骤 |
| Home | 选择首个组件 | 回到开始 |
| End | 选择末个组件 | 查看完成状态 |
| Escape | 复位并取消选择 | 暂停并取消部件选择 |

## 如何分享给其他人

**只发送一份 HTML 文件即可观看。**推荐发送 `index-dark.html`；也可以把深浅两个 HTML 一起打包成 ZIP，让接收者自行选择。

每份 HTML 都内嵌了模型、样式和运行代码，观看时无需附带 `src/`、`assets/`、`vendor/` 或其他开发文件。如果同时发送启动脚本，请将脚本和对应 HTML 放在同一文件夹中。

聊天软件或网盘的文件预览可能无法运行交互动画。请让接收者下载文件，并在浏览器中打开。

## 开发与构建

仅查看成品页面可跳过本节。修改源码并重新生成页面，需要 **Node.js 20.10 或以上版本**。构建脚本只使用 Node.js 内置模块，无需运行 `npm install`。

在项目根目录打开终端，执行：

```sh
# 生成浅色页面 index.html
node build.mjs

# 生成深色页面 index-dark.html
node build.mjs --dark
```

修改共享代码后，应分别构建深浅两个版本。页面内嵌代码，修改源码后需要重新构建并刷新 HTML 才能看到变化。

可按改动范围运行以下检查：

```sh
# 结构几何审计，并生成浅色页面
node build.mjs --audit

# 可见面算法检查
node checks/visibility.test.mjs

# 加工时间线、送料与材料状态检查
node checks/processing-model.test.mjs

# 加工机构与夹持区域的采样检查
node checks/processing-clearance.test.mjs
```

几何或可见面算法变化后，首次构建会重新计算可见面缓存，后续构建复用缓存。

### 目录说明

| 路径 | 用途 |
| --- | --- |
| `index.html`、`index-dark.html` | 可直接打开、分享的成品页面 |
| `build.mjs` | 构建入口，将图形、样式与交互打包到 HTML |
| `src/model.mjs`、`src/geometry.mjs` | 结构总成定义与几何模型 |
| `src/visibility.mjs`、`src/raster.js` | 结构图可见面处理与 Canvas 图层缓存 |
| `src/live.js`、`src/page.mjs`、`src/style.css` | 结构展示交互、页面与样式 |
| `src/processing-model.mjs` | 加工时间线、送料、锯切与材料状态 |
| `src/processing-rig.mjs`、`src/processing-geometry.mjs` | 加工机构联动与完整三维网格 |
| `src/processing-renderer.js`、`src/processing-ui.js`、`src/processing.css` | WebGL2 加工画面、播放控制与样式 |
| `assets/` | 建模参考图片和手册资料，观看成品时无需加载 |
| `vendor/` | Anatomy 工具与其许可文件 |
| `checks/`、`shots/` | 测试脚本、检查记录与截图 |
| `DESIGN.md` | 素材来源、建模范围和设计记录 |

结构模式使用 SVG 几何并缓存为透明 Canvas 图层；加工模式使用独立三维网格与 WebGL2 深度缓冲处理遮挡。结构图层缓存失败时会保留 SVG 展示，加工模式则需要 WebGL2 支持。当前加工模式尚未开展专项性能优化，设备性能会影响流畅度。

## 常见问题

**打开后只有文件预览，没有动画？**  
请下载并解压文件，再用浏览器打开 HTML，不要在聊天软件或网盘预览窗口中观看。

**进入加工模式后提示图形不可用？**  
请使用支持 WebGL2 的 Edge 或 Chrome，并检查浏览器是否启用了图形加速。结构模式仍可单独查看。

**动画没有自动播放？**  
加工模式初始为暂停状态，请点击“播放”。如果按钮显示“下一步”，说明系统启用了减少动态效果。

**修改源码后页面没有变化？**  
请重新执行对应主题的构建命令，并刷新或重新打开生成的 HTML。

## 模型与资料说明

本项目是依据照片和手册制作的结构与工作原理示意，非 PONSSE 官方 CAD 模型。外形、零件细节、机构行程、木材尺寸和分离轨迹均经过适度简化；模型单位不代表毫米或制造商规格。

结构模式中的 846 个几何实体不等于真实机器的零件数量，展开路径也不代表维修拆装顺序。加工演示未模拟液压系统、切削力或复杂碰撞，数值与采样检查不能替代工程碰撞校核。不同参考资料涉及的配置差异和建模取舍见 `DESIGN.md`。
